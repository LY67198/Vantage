# Phase Retrospectives — Design

## Goal

Add structured retrospective sections to `decision-platform-plan.md` after each Phase, serving as interview preparation material.

## Design

Insert a uniform 5-part template at the end of each Phase (1–4):

1. **完成的功能** — What was built, tech stack used
2. **遇到的问题 & 解决方案** — Problem → investigation → root cause → fix
3. **技术决策 & 思考** — Why A over B, trade-offs
4. **面试可讲述点** — 2-3 specific storylines with context, conflict, solution, result
5. **踩过的坑** — Notes for future self

## Implementation

Edit `decision-platform-plan.md`, append template after each Phase section. Content left blank for user to fill after each phase is completed.
